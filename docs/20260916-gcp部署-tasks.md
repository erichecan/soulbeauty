## 关键决策与风险

- **Cloud SQL 成本**：db-f1-micro 约 $10-15/月，是唯一持续成本。用户已知悉并选择。
- **Cloud Run 连 Cloud SQL**：走 Unix socket `/cloudsql/<CONNECTION_NAME>`，Prisma 7 用 `@prisma/adapter-pg`，连接串形如
  `postgresql://user:pass@localhost/db?host=/cloudsql/<CONNECTION_NAME>`，部署时需 `--add-cloudsql-instances`。
- **公开仓库**：`public/images/` 下客户团队成员照片将公开可见，已向用户提示。
- **src/generated/prisma 被 gitignore**：Docker 构建阶段必须跑 `prisma generate`，否则构建失败。
- **迁移与 seed 在哪跑**：本地通过 Cloud SQL Auth Proxy 连生产库执行一次，不放进容器启动流程（避免每次冷启动重复跑）。
